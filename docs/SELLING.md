# Selling Guide

Early Access checkout: https://app.lemonsqueezy.com/share/1257430

## Positioning

Sell Quantum Terminal Pro Dashboard as a professional control surface, not as a
profit-guaranteeing trading bot.

Core message:

> Add a premium risk console and manual intervention layer to your trading bot.

## Best Buyers

- Traders running bots on AWS or VPS.
- Python bot developers.
- Quant hobbyists who need better visibility.
- Small trading teams that want a lightweight operations panel.

## Pricing

Recommended launch offer:

- Start with Early Access at $149 for the first buyers.
- Move the default product to Pro at $249 after screenshots, testimonials, and
  installation videos are ready.
- Keep Setup Included at $499 for customers who want the dashboard working on a
  server without touching Linux.
- Quote Custom Adapter at $999+ because it is engineering work, not a generic
  product sale.

## Sales Channels

Primary channels:

| Channel | What To Sell | Why It Fits |
| --- | --- | --- |
| GitHub | Public product page, docs, screenshots, credibility | Developers trust a clean repository before buying trading tools. |
| Gumroad or Lemon Squeezy | Early Access and Pro ZIP/license checkout | Fastest way to accept card payments and deliver files. |
| X / Twitter | Build in public, short demo clips, risk-management threads | Trading bot users already discover tools there. |
| Reddit | Educational posts in bot, algo trading, and self-hosting communities | Good for adapter-first positioning, but avoid spam. |
| Discord/Telegram trading communities | Setup Included and Custom Adapter | Buyers often need help connecting their own bot. |
| Freelancer platforms | Installation and custom adapter gigs | Converts non-technical buyers into $499-$999+ services. |

Channel order for launch:

1. GitHub README and docs as the trust layer.
2. Short demo video or screenshots from a paper-trading setup.
3. Gumroad/Lemon Squeezy checkout for Early Access.
4. X/Twitter posts explaining the problem: bot is running, but the trader has no
   clean risk console.
5. Direct outreach to bot developers who already have Binance, OKX, Bybit, or
   Alpaca scripts.

## Offer Copy

Short headline:

> A self-hosted trade manager and risk dashboard for serious trading bots.

One-line offer:

> Connect your Binance, OKX, Bybit, Alpaca, or custom bot to a premium dashboard
> for positions, orders, diagnostics, analytics, and manual intervention.

Setup offer:

> I install Quantum Terminal Pro on your AWS/VPS server and connect it to your
> bot's state files and manual action queue.

## GitHub Strategy

Recommended:

- Public GitHub repo for README, screenshots, docs, and demo config.
- Public source is acceptable while the product is early and credibility matters.
- Later, move premium adapters, installer scripts, or advanced auth into a paid
  package if copying becomes a problem.
- License that forbids redistribution.

This protects the code while still making the product look credible.

## Claims To Avoid

Avoid:

- guaranteed profit,
- fixed win rate promises,
- "AI prints money",
- account growth guarantees,
- live trading claims before the user's own paper test.

Use:

- self-hosted,
- adapter-first,
- exchange-neutral,
- manual intervention layer,
- risk visibility,
- operational dashboard.
